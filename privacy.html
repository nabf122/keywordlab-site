개인정보처리방침

시행일 및 최종 수정일: 2026년 11월 13일

이 문서는 KeywordLab의 공개 소개 사이트와 현재 운영자가 로컬에서 사용하는 개발 도구의 데이터 처리 범위를 설명합니다. 공개 사이트는 서비스 소개 용도이며, 방문자의 Google 계정 연결이나 분석 요청을 받지 않습니다.

1. 운영자 및 문의

운영자는 GitHub 사용자 nabf122입니다. 프로젝트 및 데이터 처리 문의 경로는 운영자 GitHub 프로필에서 확인할 수 있습니다. 공개된 공간에 서비스 계정 키, 토큰, 고객 ID 등 계정 정보를 게시하지 마세요.

2. 공개 소개 사이트에서 처리하는 정보

이 사이트에는 회원가입, 로그인, 입력 폼, 자체 분석 스크립트 또는 광고 스크립트가 없습니다. 운영자는 이 페이지를 통해 방문자의 Google Ads 데이터, 키워드 입력 또는 인증 토큰을 수집하지 않습니다.

호스팅 제공자인 GitHub는 사이트 제공 및 보안을 위해 방문자의 IP 주소 등 정보를 처리할 수 있습니다. 관련 사항은 GitHub 개인정보처리방침을 참고하세요. 외부 링크를 누르면 해당 서비스의 정책이 적용됩니다.

3. 로컬 개발 도구의 Google 데이터 접근

현재 개발 도구는 운영자가 설정한 서비스 계정으로 Google OAuth 인증을 수행하고, Google Ads API에서 직접 접근 가능한 계정의 리소스 이름과 고객 ID를 조회합니다. 이 정보는 연결 및 계정 접근 확인 용도로만 사용합니다. 공개 소개 사이트에서는 이러한 요청을 수행하지 않습니다.

현재 키워드 분석 결과는 가상 데이터이며 Google Ads에서 실제 키워드 검색량·CPC·연관어를 조회하지 않습니다. 광고 캠페인 생성·수정, 결제 변경, 사용자 권한 변경도 현재 연결 모듈에서 수행하지 않습니다.

4. 저장 및 보관

서비스 계정 JSON 키는 운영자의 로컬 파일로 보관하고 백엔드에서만 읽습니다. 인증 토큰은 서버 메모리에서 관리하며, 계정 목록과 연결 확인 결과는 서버 메모리에 보관합니다. 연결 결과는 30초간 재사용하고 서버 종료 또는 재시작 시 메모리에서 제거됩니다. 마지막 확인 결과는 다음 확인 시 갱신됩니다.

현재 연결 모듈은 키, 토큰 또는 계정 목록을 데이터베이스에 저장하지 않으며 공개 소개 사이트나 GitHub 저장소로 전송하지 않습니다.

5. 사용·공유 범위

현재 Google 데이터는 운영자가 요청한 인증 및 계정 조회 확인에만 사용합니다. 판매하거나 광고 타기팅, 범용 AI 모델 학습에 사용하지 않습니다. 인증과 조회를 수행하기 위해 필요한 요청은 Google에 전송합니다. 공개 사이트 호스팅을 위한 GitHub의 정보 처리는 2항에 설명되어 있습니다.

6. 접근 철회 및 삭제

운영자는 Google Ads의 관리 → 액세스 및 보안에서 서비스 계정의 접근 권한을 제거하거나 Google Cloud에서 키를 폐기할 수 있습니다. 로컬 키 파일은 별도로 삭제해야 하며, 서버 메모리의 토큰과 계정 목록은 서버를 종료하여 제거할 수 있습니다.

7. 변경 안내

외부 사용자 로그인, 실제 키워드 데이터 조회, 데이터베이스 저장 또는 공개 분석 서비스가 추가되면 실제 처리 범위를 반영해 이 방침을 갱신합니다. 변경된 방침과 시행일은 이 페이지에 게시합니다.
